Initial setup​

  1. Install NodeJS 18.19.0 (https://nodejs.org/download/release/v18.19.0/node-v18.19.0-x64.msi).
  2. Install/update npm globally: npm i -g --update npm.
  3. Install gulp globally: npm i -g gulp.
  4. Install typescript 5.8.3 globally: npm i -g typescript@5.8.3.
  5. Install ts-patch globally: npm i -g ts-patch.
  6. Install rollup globally: npm i -g rollup.
  7. Install pnpm 9.0.1 globally: npm i -g pnpm@9.0.1.
  8. Run pnpm setup: pnpm setup.
  9. Initialize git LFS: (from repo root) git lfs install.
  10. Install local node_modules: (from repo root) pnpm i.

Setup .env file​

Copy the .env.example file in the repo root and rename it to .env. Then change the parameters in the new .env file to your liking. The .env file should not be tracked by git and so any changes you make to it will remain local.
