Defined in: src/workingtitle-instruments-g3x-touch/html_ui/Shared/UiSystem/UiViewTypes.ts:11

Transient: "Transient"

Defined in: src/workingtitle-instruments-g3x-touch/html_ui/Shared/UiSystem/UiViewTypes.ts:17
